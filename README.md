# Meu-Tom para ChatGPT

Revise uma mensagem sem perder seu jeito de escrever. Em um novo chat, digite **Meu-Tom** e cole o rascunho. A habilidade considera o destinatário, suas preferências e os exemplos de escrita disponíveis para devolver uma mensagem pronta para copiar.

## Instalação

1. [Baixe o projeto em ZIP](https://github.com/Caua-wi/Meu-Tom-ChatGPT/archive/refs/heads/main.zip).
2. Em um chat com suporte a habilidades pessoais e anexos, anexe o ZIP e envie: **“Instale a habilidade meu-tom que está neste arquivo.”**
3. Após a confirmação da instalação, abra um novo chat e envie seu primeiro rascunho.

## Experimente

**O que você digita**

> Meu-Tom, é pro grupo de amigos: gente acho que chego umas oito se eu atrasar aviso aqui

**Uma revisão possível**

> Gente, acho que chego umas oito. Se eu atrasar, aviso aqui.

Para ajustar o resultado, dê um exemplo seu ou indique uma preferência concreta, como “No grupo de amigos, prefiro manter ‘tô’ e ‘pra’”. Você também pode indicar quando uma orientação vale só para aquela mensagem.

## Personalização entre conversas

A habilidade usa o contexto disponível no ChatGPT de cada pessoa. No primeiro uso, o próprio rascunho já serve como referência. Para reaproveitar uma preferência em outro chat, ela precisa estar disponível por meio da memória ou ser informada novamente. O projeto contém apenas as instruções e os metadados da habilidade.
